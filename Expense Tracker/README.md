# Expense Tracker

## Description
The Expense Tracker is a web application that helps users manage their finances by allowing them to input their expenses and income, categorize transactions, and see a summary of their financial activities. The application is built using HTML, CSS, and JavaScript, and it uses local storage to persist the user's transactions.

## Features
- User-friendly web interface
- Input fields for date, description, category, and amount for each transaction
- Separate sections for income and expenses
- Buttons for adding, editing, and deleting transactions
- Calculation of total income, total expenses, and net income
- Filtering transactions by category
- Data visualization using a pie chart to represent the distribution of expenses by category
- Responsive design for various screen sizes (desktop, tablet, and mobile)
- Basic input validation to ensure valid data entry
- Persistence using local storage

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/expense-tracker.git
   ```
2. Navigate to the project directory:
   ```bash
   cd expense-tracker
   ```

## Usage
1. Open the `index.html` file in your web browser.
2. Use the form to add new transactions by providing the date, description, category, and amount.
3. View the transaction history, summary, and pie chart visualization.
4. Filter transactions by category using the dropdown filter.
5. Edit or delete transactions as needed.

## Code Structure
- `index.html`: The main HTML file that contains the structure of the web application.
- `styles.css`: The CSS file for styling the web application.
- `script.js`: The JavaScript file for handling the dynamic behavior of the application.
- `README.md`: The README file explaining how to use the Expense Tracker and providing brief documentation on the code structure.
